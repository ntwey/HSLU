Ein [[Trojan-Proxy]] ist eine fortschrittliche Zensurumgehungstechnologie. Er ist so konzipiert, dass sein Datenverkehr für Firewalls wie gewöhnlicher HTTPS-Traffic aussieht. Der Client baut eine TLS-Verbindung zum Server auf und übermittelt ein gehashtes Passwort. Ist das Passwort korrekt, öffnet sich ein Proxy-Tunnel für den Nutzer; ist es falsch, verhält sich der Server wie ein normaler Webserver und zeigt eine harmlose Website an. Für DPI-Analysen ist dies nicht von einem normalen Webseiten-Besuch zu unterscheiden.
